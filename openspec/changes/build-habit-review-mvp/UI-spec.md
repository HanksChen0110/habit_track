# 循迹 UI / UE 规格

> 状态：已确认并实现。本文是当前 MVP 的 UI 参考源；业务规则、数据结构和统计口径仍以同目录 `design.md` 与能力 `spec.md` 为准。
>
> 适用范围：`今天 / 本周 / 洞察 / 管理`四个一级页面、首次进入页、恢复页、弹窗与状态反馈。后续界面实现如与本文冲突，应先更新本文和相关 OpenSpec 能力规格。

## 1. 设计原则与边界

- 产品是本地优先的个人习惯记录与复盘工具，视觉应安静、克制、可信；不使用游戏化连续天数、健康仪表盘、社交或 AI 建议的视觉语言。
- 信息层级主要通过留白、字体、细边框和有限的表面层级建立；不能把每项信息都包装成同等对比度的卡片。
- 每页只有一个主操作：今天页为创建习惯、本周页为周切换、洞察页为时间范围选择、管理页为创建习惯。危险操作独立使用危险色。
- 当前仅支持浅色主题；不接入在线字体、远程图片、第三方图表库或 GSAP 等动效库。
- 所有状态都以文字、数值或形状表达，不得只依赖颜色。

## 2. 视觉令牌

### 2.1 色彩

| 语义 | Hex / 值 | 使用场景 |
| --- | --- | --- |
| 画布 | `#E9ECEA` | 应用背景 |
| 主表面 | `#FFFFFF` | 面板、按钮、列表行 |
| 半透明主表面 | `rgba(255,255,255,.94)` | 大型内容面板 |
| 次级表面 | `#F2F4F2` | 今日进度块 |
| 输入表面 | `#FAFBFA` | 表单输入与图表背景 |
| 主文字 | `#1E191A` | 正文与页面标题 |
| 主操作 / 深色表面 | `#20191B` | 主按钮、主要 KPI、洞察线索 |
| 次级文字 | `#666D69` | 辅助说明、数据标签 |
| 标签文字 | `#707672` | eyebrow 与导航非激活态 |
| 分隔线 | `#DFE3E0` | 控件和卡片基础边框 |
| 强分隔线 | `#D2D8D4` | 悬停边框 |
| 淡紫强调表面 | `#F2EDFF` | 已选范围、辅助选中状态 |
| 紫色强调 | `#A98BEE` | 进度、选中边框、数据强调 |
| 深紫文字 | `#6847B4` | 完成状态和强调文字 |
| 危险操作 | `#7F3036` | 归档确认、破坏性操作 |
| 错误文字 | `#A23F48` | 字段和导入失败 |
| 焦点环 | `rgba(151,113,238,.38)` | 键盘焦点 3px 外框 |

除本文表中的语义色外，局部透明度只可用于阴影、背景纹理、禁用态和图表叠加；不得另行引入品牌主色。

### 2.2 字体与数字

- 字体：项目内打包的 `Noto Sans SC Variable`；回退 `PingFang SC`、`Microsoft YaHei`、系统无衬线。不得请求在线字体。
- 正文基准：14–16px，行高 `1.5`；移动端输入框固定为 16px，避免 iOS 自动缩放。
- 页面标题：`clamp(28px, 3vw, 42px)`，字距 `-.055em`，行高 `1.1`；小屏为 30px。
- eyebrow：12px、字重 650、字距 `.08em`、大写英文；辅助标签与表格文字为 11–13px。
- 大数据：今日进度 42px、本周摘要 64px、周整体执行率 74px、洞察 KPI 28px；数字使用 `font-variant-numeric: tabular-nums`。
- 习惯、日期及统计名称必须允许换行，不以截断代替可读性。

### 2.3 空间、圆角与层级

| 类别 | 规范 |
| --- | --- |
| 基础栅格 | 4px；常用间距为 8、12、18、24、30、38、48px |
| 应用外边距 | 桌面 28px；平板 14px；手机 9px |
| 内容最大宽度 | 1200px，水平居中 |
| 主要面板圆角 | 24px；手机 18px |
| 次级面板 / 图表圆角 | 18–20px |
| 列表行圆角 | 15–16px |
| 按钮、输入、日期单元圆角 | 11–13px；范围切换可为 999px 胶囊 |
| 最小交互尺寸 | 44 × 44 CSS px；相邻触控目标至少 8px 间距 |
| 浮层阴影 | 导航 `0 16px 40px rgba(34,31,32,.05)`；面板 `0 24px 70px rgba(38,35,36,.07)`；弹窗 `0 32px 90px rgba(29,24,25,.2)` |
| 层级 | 内容 1、移动导航 10、弹窗 20、Toast 30、跳转主内容链接 50 |

背景仅可使用低对比日期点阵：`rgba(112,118,114,.13)`、18px 网格，并以局部 radial mask 控制范围；不得使用旅行、健康或具象插图。

## 3. 应用壳与导航

### 3.1 桌面（1024px 及以上）

- 顶部导航高度 66px，圆角 18px，采用居中胶囊形白色表面。
- 一级导航固定为“今天 / 本周 / 洞察 / 管理”；每个桌面标签最小宽度 78px，激活态为深色实底白字，非激活态为次级文字。
- 右侧显示“仅存于此设备”，这是数据边界说明，不是账号入口。
- 主内容与顶部导航共用 1200px 最大宽度。

### 3.2 手机与平板（320–1023px）

- 顶栏高度 58px，仅展示品牌与“仅存于此设备”；桌面导航隐藏。
- 底部固定四项导航，高度 68px，左右 12px，底部为 `max(12px, safe-area-inset-bottom)`；内容底部预留至少 92px。
- 四个一级入口必须同时可达，图标与文字同时出现；激活项为深色表面白字。
- 所有页面单列；不得用横向页面滚动换取信息密度。共现矩阵内部可横向滚动，且仅该容器滚动。

## 4. 页面信息架构与交互

### 4.1 今天

阅读和操作顺序固定为：日期及主操作 → 今日完成量 → 最近七天补记 → 当天计划。

- 桌面：主记录面板与 330px 本周摘要侧栏采用 18px 间距；两者底边对齐。摘要侧栏包含本周执行率、实际/计划完成量、紧邻周变化、完整周报入口与“只呈现执行事实”的说明。
- 手机：隐藏侧栏，在计划列表后提供“查看本周复盘”全宽入口。
- 今日进度块使用次级表面，显示 `实际 / 计划`、完成文案和淡紫进度线；进度不可只以色彩表达。
- 最近七天桌面为七等分日期单元；手机可在日期条内横向查看，单元最小宽 44px。已选日期使用淡紫表面、紫色边框和圆点。
- 习惯行桌面为一行，手机改为上下布局，名称与状态在上、加减器在下；长名称不能挤压加减控制。

### 4.2 本周

阅读顺序固定为：周范围与进行中状态 → 整体执行率 → 环比 → 七日执行率 → 最佳/最差日期与完成单位。

- 周范围切换按钮须有“上一周 / 下一周”可读名称；当前周不得继续向未来周切换。
- 整体执行率为深色主卡；环比为独立辅助卡，正向使用淡紫，负向使用浅红，不得仅通过颜色说明方向。
- 七日图固定使用柱形图：无计划明确显示“无计划”，每根柱同时展示百分比、星期和日期。
- 日期事实区采用三列，手机改为单列；不推断未完成原因。

### 4.3 洞察

阅读顺序固定为：观察窗口与总览 → 执行率趋势 → 本期线索 → 习惯共现 → 习惯表现与下钻。

- 观察窗口为 7 / 30 / 90 天胶囊切换，选中项为淡紫表面与紫色边框。
- 四项总览采用四列（小屏两列）；“整体执行率”为唯一深色主卡，其余为低对比白色信息卡。
- 趋势使用原生 SVG：整体为深色实线，已选习惯为紫色实线；30 天窗口允许使用低透明度平滑线。趋势点的可点击区至少 44px，并支持键盘 Enter/Space。
- 本期线索为深色辅助面板，必须显示样本量、百分比与“伴随关系不代表因果”。
- 共现矩阵按“同时达标 / 同时未达标 / 表现相反”切换；表格文字、数值和样本状态必须独立于色彩可读。
- 详情在桌面右侧 sheet、手机底部 sheet 打开；关闭后保留范围、选择与滚动状态。

### 4.4 管理

- 桌面为主工作区与 330px 数据侧栏，18px 间距；两者底边对齐。移动端侧栏顺序排在习惯列表后。
- 主工作区优先显示“进行中”习惯，其后为已归档习惯；每行显示名称、目标/日期与编辑、归档操作。
- 数据侧栏使用文件图标、备份说明、导出主按钮、导入次按钮和替换风险提示。导入与归档均须经过确认弹窗。
- 归档、完整替换等危险操作使用危险色，且不能与日常主操作混淆。

### 4.5 首次进入、恢复页与弹窗

- 首次进入只提供“开始记录”和“载入示例”两个选择；前者为深色主选项，后者为白色次选项，不主动创建示例数据。
- 恢复页和空状态应提供单一、可操作的下一步，不伪造统计数据。
- 桌面弹窗最大宽度 480px，圆角 22px；手机从底部出现，宽度 100%、圆角 `24px 24px 0 0`，最大高度 92vh，并尊重底部安全区。

## 5. 可访问性、反馈与动效

- 在应用壳开头提供“跳至主要内容”链接；所有按钮、链接和输入在键盘焦点时显示 3px 紫色焦点环。
- 所有图标按钮提供中文 `aria-label`；表单显式标签关联输入，错误紧邻字段并用 `role="alert"` 播报。
- 保存、导入和跨标签更新使用 `aria-live="polite"` Toast；Toast 不夺取焦点。禁用控件保留原生 `disabled` 语义并降低强调度。
- 主要交互采用 180–240ms 的 opacity / transform / background / border 过渡；不得通过 width、height、top 或 left 制造布局跳动。`prefers-reduced-motion` 下将动画缩短到近乎即时。
- 文本对比度满足普通文字至少 4.5:1；深色背景上的次级文字至少 3:1。

## 6. 验收与非目标

- 在 320、390、768、1024、1440px 视口中，页面主体不得出现横向溢出；长习惯名称允许换行。
- 核心流程（创建、记录、周报、洞察、管理、导入导出）可完全通过键盘操作。
- 不新增深色模式、主题切换、账号头像、云同步、提醒、连续天数、社交分享、图片素材或 AI 文案。
- 如需新增视觉主题、修改色彩语义、增加一级导航或改变断点，必须先修改本文与受影响能力规格，再修改实现。
