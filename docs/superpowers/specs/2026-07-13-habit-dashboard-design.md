# 习惯追踪与可视化仪表盘：MVP 设计

> **状态：已替代（保留作探索记录）**
> 当前实现依据为 [`openspec/changes/build-habit-review-mvp/`](../../../openspec/changes/build-habit-review-mvp/)；其中不包含本文件所述的连续天数、近 30 天热力图或长期趋势。不得以本文件作为开发验收依据。

## 1. 目标与边界

### 目标

为一个个人用户提供一个本地网页工具，用最少步骤完成每日习惯打卡，并从仪表盘看到今天的执行情况、持续性和近 30 天趋势。

成功标准：用户能在一次浏览器会话中创建习惯、完成当天打卡、补记一天记录，并在刷新页面后仍能看到记录和正确的仪表盘统计。

### 明确不做

- 账号、登录、多人协作、云同步或跨设备同步。
- 推送提醒、日历订阅、社交分享或排行榜。
- 复杂的频率规则、标签体系、笔记、AI 分析或收费功能。

## 2. 产品决策

选择纯前端单页 Web 应用，使用浏览器本地存储保存数据。

原因：这是个人工具的最短闭环，无须部署后端或处理账户与隐私数据；同时保留 JSON 导入导出，作为用户更换设备或清理浏览器前的迁移方式。该选择不承诺跨设备同步。

## 3. 信息架构与页面

### 今日打卡

默认首页，包含：

- 顶部日期及“今天已完成 X / Y 项”的进度。
- 活跃习惯列表；每行显示名称、每日目标、当天已完成次数和加一/减一控件。
- “管理习惯”入口：可新增、编辑、归档一个习惯。
- 最近 7 天的小型完成摘要，帮助用户确认是否漏记。

每日目标只支持正整数。目标为 1 的习惯可直接勾选；目标大于 1 时显示已完成次数并通过加减调整。当天完成次数达到目标即视为“完成”。

### 仪表盘

包含：

- 今日完成率：已达目标的活跃习惯数 / 活跃习惯总数；没有活跃习惯时显示“先创建一个习惯”。
- 最长连续天数与当前连续天数：按每个习惯分别计算，页面显示习惯名称与对应数值。
- 近 30 天热力图：每一天按全局完成率着色；当天未结束也按当前完成率显示。
- 每个活跃习惯的近 30 天完成趋势：按天展示完成或未完成，目标大于 1 的习惯按“完成次数 / 目标”显示。

### 数据管理

位于“管理习惯”页底部，提供：

- 导出：下载完整 JSON 数据。
- 导入：选择此前导出的 JSON，先检查结构，再以导入文件完整替换当前本地数据；替换前要求用户二次确认。

## 4. 数据模型与计算规则

所有日期均为用户浏览器本地时区的 `YYYY-MM-DD`。

```text
Habit
  id: string
  name: string
  targetPerDay: positive integer
  createdAt: ISO timestamp
  archivedAt: ISO timestamp | null

Completion
  habitId: string
  date: YYYY-MM-DD
  count: non-negative integer

Store
  version: 1
  habits: Habit[]
  completions: Completion[]
```

规则：

- 当天完成次数限定在 `0..targetPerDay`；数值归零时删除对应 `Completion` 记录。
- 习惯归档后不出现在今日打卡和默认仪表盘，但既有历史记录保留在导出数据中。
- 某习惯某日 `count >= targetPerDay` 时，该日为完成日。
- 当前连续天数从今天向前计算；若今天尚未达标，则从昨天向前计算，避免在一天开始时把连续记录立刻归零。
- 最长连续天数在该习惯创建日至今天的可用记录范围内计算；缺失日期视为未完成。
- 全局日完成率为当日活跃习惯中已达标习惯的比例；分母为 0 时无完成率。

## 5. 交互与异常处理

- 新增或编辑时，名称去除首尾空格且不能为空；同名习惯允许存在，不额外限制。
- 归档操作需确认；归档不删除历史数据。
- 导入文件必须是版本为 1 的 JSON，且每条数据满足字段与数值约束；不合法时展示错误，当前数据不变。
- 本地存储不可用或写入失败时，展示明确提示，避免把未保存的打卡误报为已保存。
- 导出结果使用可读缩进 JSON，并包含版本号。

## 6. 可用性与视觉原则

- 今日完成操作应在一屏内完成，不要求跳转到表单。
- 状态不能只靠颜色区分；完成、未完成和进度须有文字或数值。
- 小屏优先：仪表盘卡片纵向排列，热力图可横向滚动。
- 中文文案直接、克制，不使用评分或羞耻式提醒。

## 7. 实施边界与验证

实现将拆为三块：领域数据与统计计算、持久化与导入导出、页面交互与仪表盘展示。模块之间通过明确的数据类型和纯计算函数连接。

验收验证：

1. 创建每日 1 次和每日多次的习惯，刷新后仍存在。
2. 调整今天次数，今日完成率与列表状态同步变化。
3. 补记过去日期，近 30 天热力图和连续天数按规则更新。
4. 归档习惯后不再干扰活跃统计，历史记录仍能导出。
5. 导出后清空或换浏览器环境，再导入，可恢复习惯和完成记录。
6. 对不合法导入文件，应用拒绝替换且保留原始数据。
