# “循迹”高保真原型设计系统

> 状态：已实现。本文记录本轮前端原型采用的视觉、布局和交互约定；产品规则仍以 `openspec/changes/build-habit-review-mvp/` 为唯一规格来源。

## 1. 视觉方向

“循迹”使用安静、轻量的本地工具感：浅灰画布承接白色内容面板，近黑褐色用于主要操作，淡紫色只标记选中、完成进度和正向变化。背景的日期点阵暗示持续记录，不使用旅行图片或具象插画。

| 用途 | 值 |
| --- | --- |
| 应用背景 | `#E9ECEA` |
| 主表面 | `#FFFFFF` / 94% 不透明白 |
| 主文字、主按钮 | `#1E191A` / `#20191B` |
| 次级文字 | `#666D69` |
| 强调紫 | `#A98BEE` |
| 淡紫表面 | `#F2EDFF` |
| 分隔线 | `#DFE3E0` |
| 危险操作 | `#7F3036` |

字体为项目内打包的 `Noto Sans SC Variable`，回退到系统中文无衬线字体，不请求在线字体。正文基准 14–16px，页面标题 28–42px；数字结果使用更大的字号与紧凑字距。

## 2. 空间与组件

- 基础间距以 4px 倍数组织，页面核心间距为 18、24、30、38px。
- 按钮和输入框圆角 11–12px，列表行 15–16px，主要面板 24px。
- 所有可点击目标最小为 44 × 44 CSS 像素。
- 信息层级主要依靠留白、细边框和字体，阴影仅用于浮动导航、弹窗与顶层面板。
- 一级导航为“今天 / 本周 / 洞察 / 管理”四项；主要组件包括：顶部/底部导航、习惯行与加减器、日期条、周报柱形图、数据面板、底部抽屉/桌面弹窗和状态 Toast。

## 3. 响应式规则

### 手机与平板：320–1023px

- 内容单列，底部固定“今天 / 本周 / 洞察 / 管理”四项导航。
- 今天页先显示日期、完成量、最近七天和习惯列表，并提供明确的“查看本周复盘”入口。
- 表单与确认框在手机底部展开；长习惯名称换行，加减器保持独立一行。
- 管理页的数据备份区域排在习惯列表后，不产生横向滚动。
- 洞察页提供 7 / 30 / 90 天范围切换，总览、执行率趋势、本期线索、共现矩阵、习惯排行和页内下钻；详情以底部 sheet 展开。

### 桌面：1024px 及以上

- 最大 1200px 居中画布，顶部使用胶囊导航。
- 今天页为记录主栏加本周摘要侧栏；管理页为习惯列表加数据侧栏。
- 周报使用宽版七日/统计范围柱形图，并在同屏展示整体执行率、环比和日期规律。
- 洞察页保留同一组总览、趋势、本期线索、矩阵、排行和下钻组件；详情在右侧 sheet 展开。

## 4. 交互状态

- 完成量限定在 `0..targetPerDay`；达到目标时增加按钮禁用，归零时删除记录。
- 选择最近七天中的历史日期后，页面标题变为“修正漏记”，并只展示该日有效习惯。
- 完成与部分完成同时通过数字、文字和图形表达，不只依赖颜色。
- 保存、归档和导入结果通过 `aria-live` 状态 Toast 播报；失败时保留已持久化快照。
- 创建/编辑错误显示在对应字段附近。进入历史统计的每日目标被禁用，并说明需归档后新建。
- 导入先校验并显示习惯数与记录数，用户二次确认后才原子替换。
- 弹窗支持 Escape 关闭、Tab 焦点循环，并在关闭后把焦点还给原触发控件。
- 页面、弹窗和进度变化使用 180–240ms 动效；系统启用“减少动态效果”时，将动效缩短到近乎无动画。
- 洞察窗口只统计今天之前已结束的本地日，避免未结束当天干扰趋势；本周复盘仍保留今天，承担当周进行中进度的展示职责。

## 5. 页面空错状态

- 首次进入：只提供“开始记录”和“载入示例”两个选择。
- 今天无习惯：展示单一创建入口，不生成默认数据。
- 周内无有效计划：显示“本周暂无可复盘的数据”，不伪造 0%。
- 导入失败：展示具体校验错误，当前 Store 不变。
- 本地数据损坏：进入独立恢复页，明确声明没有清空或覆盖原数据，仅接受有效 JSON 备份恢复。

## 6. 后续正式产品沿用

正式产品可以复用本文件中的颜色、间距、响应式断点和交互状态。若后续引入账号、后端同步或新的计划规则，应先更新 OpenSpec，再决定是否扩展界面；不得通过隐藏字段或预留入口提前加入未确认能力。
